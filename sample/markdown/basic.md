# Markdown基本記法サンプル

このファイルでは、GitHub風Markdownの主要な記法が正しくレンダリングされるかを確認できます。

## テキスト装飾

これは通常のテキストです。**太字**、*イタリック*、~~取り消し線~~、`インラインコード` が使えます。

> これは引用ブロックです。
> 複数行にまたがることもできます。

## リスト

### 順序なしリスト
- りんご
- みかん
  - 温州みかん
  - デコポン
- バナナ

### 順序付きリスト
1. 最初の項目
2. 次の項目
3. 最後の項目

### タスクリスト
- [x] 完了したタスク
- [ ] 未完了のタスク
- [ ] もう一つの未完了タスク

## テーブル

| 名前 | 役割 | 状態 |
| :--- | :---: | ---: |
| Alice | 開発者 | アクティブ |
| Bob | デザイナー | 休暇中 |
| Charlie | PM | アクティブ |
