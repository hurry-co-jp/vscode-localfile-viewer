# Local File Viewer サンプル集

この `sample/` フォルダには、Local File Viewer の各機能を確認するためのサンプルファイルが含まれています。

## フォルダ構成

| フォルダ | 内容 |
| :--- | :--- |
| `markdown/` | 基本記法、Mermaidダイアグラム、Marpスライド |
| `code/` | JavaScript, Python, ShellScript, JSON, CSV |
| `image/` | SVG画像 |

## 使い方

1. VSCodeのエクスプローラーで `sample` フォルダを右クリック
2. **"Open with Local File Viewer"** を選択
3. 左側のファイルリストから各サンプルを選んで表示を確認
